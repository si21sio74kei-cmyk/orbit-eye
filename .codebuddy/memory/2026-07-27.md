## DSM-7 3D 地球坐标修正 (dashboard.js)

**问题**:首屏 3D 地球的红点(澳门测控站)与绿点(ISS)整体相对贴图偏移 180°。

**根因**:`static/js/dashboard.js` 第 215 行的 `llv(lat, lon, r)` 函数把经纬度转 3D 坐标时,
```
theta=lon*Math.PI/180
```
缺少 `+180°` 偏移。Three.js `SphereGeometry` 默认 UV + 标准等距圆柱地球贴图(`earth-blue-marble.jpg`,
经度 0° 在图中央)要求经度按 `theta = (lon + 180) * PI / 180` 计算才能正确对齐(对应 `three-globe` 库的 `geoToVector3` 标准实现)。

**修复**:`theta=lon*Math.PI/180` → `theta=(lon+180)*Math.PI/180`

**经验**:
- 此类 3D 地球标记偏移类 bug,若为「整圈相反」特征(180° 偏移),几乎都是 lat/lon→3D 转换公式缺 `+180`。
- 修改后,用户可能因浏览器静态资源强缓存看不到效果,需提示 `Ctrl+F5` 硬刷新。
